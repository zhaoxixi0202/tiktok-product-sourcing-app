使用建议

新店优先

选低重量、低售后、镜头前变化明显的商品。饰品、抓夹、卡包比大件和尺码款更适合冷启动。

达人样品

先寄 5-10 个低成本高展示款，要求确认挂车视频，再扩大样品预算。

API 接入

后端可调用 Skill 的 product_rank.py；前端也支持导入第三方 API 导出的标准 JSON。
