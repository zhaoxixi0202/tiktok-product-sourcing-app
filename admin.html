密钥配置

按 Apify 官方方式获取 token，并只存到服务器环境变量，不在页面里保存明文。

打开 Apify 控制台

1. 获取 Token

进入 Apify Console 的 API & Integrations 页面，复制 API token。不要发给别人，也不要提交到代码仓库。

2. 本地开发

在项目根目录的 .env 中配置 APIFY_TOKEN。修改后需要重启本地服务。

APIFY_TOKEN=your-apify-token

3. 线上发布

在 Vercel、Render、Railway、Cloudflare 等平台的 Environment Variables / Secrets 中配置。

APIFY_TOKEN
ADMIN_PASSWORD

4. 调用方式

后台使用 Apify 同步 dataset 输出接口：运行 Actor，等待短任务结束，并读取结果。

/actors/{actorId}/run-sync-get-dataset-items

5. 热销榜接口

如果使用 4Seller 或 Generic 数据源，把 API Key 放到环境变量。前台“后台抓取”会直接返回热销榜，不依赖 TikTok 页面登录。

FOURSELLER_API_KEY
TIKTOK_SOURCING_API_KEY
